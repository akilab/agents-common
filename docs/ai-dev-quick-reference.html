01

まず、ファイル名

!

AGENT.md ではなく AGENTS.md。 Codex の標準指示ファイルは複数形です。Claude Code の標準指示ファイルは CLAUDE.md。このリポジトリの運用では、両方を各ツールの設定ディレクトリへ置き、CLAUDE.md が同居する AGENTS.md を読み込みます。

Codex

AGENTS.md
グローバル~/.codex/AGENTS.md
プロジェクト<repo>/AGENTS.md
一時的な上書きAGENTS.override.md

より深いディレクトリの指示が後から結合されます。

Claude Code

CLAUDE.md
グローバル~/.claude/CLAUDE.md
プロジェクト<repo>/CLAUDE.md または <repo>/.claude/CLAUDE.md
追加読み込み@AGENTS.md

Claude Code は AGENTS.md を自動では読まないため、必要なら CLAUDE.md からインポートします。

02

skill か skills か

ディレクトリは複数形

skills/ を使います。各スキルを配下の独立したディレクトリとして置きます。

入口は大文字・単数形

必須の入口ファイルは SKILL.md。skill.md ではありません。

一つのスキル = 一つの仕事

SKILL.md に指示、必要に応じて scripts/、references/、assets/ を同居させます。

Codex の配置

.agents/skills
個人用~/.agents/skills/<skill-name>/SKILL.md
プロジェクト用<repo>/.agents/skills/<skill-name>/SKILL.md

Claude Code の配置

.claude/skills
個人用~/.claude/skills/<skill-name>/SKILL.md
プロジェクト用<repo>/.claude/skills/<skill-name>/SKILL.md
03

サブエージェントは両方ある。ただし形式が違う

Codex

TOML

標準の default、worker、explorer があるため、通常はファイルを作らなくても並列作業できます。独自エージェントを作るときだけ TOML を追加します。

個人用カスタムエージェント~/.codex/agents/<name>.toml
プロジェクト用カスタムエージェント<repo>/.codex/agents/<name>.toml

最低限 name、description、developer_instructions を定義します。

Claude Code

Markdown + YAML

Explore・Plan・General-purpose などの標準サブエージェントがあります。繰り返し使う専門役を作る場合は Markdown ファイルで定義します。

個人用カスタムエージェント~/.claude/agents/<name>.md
プロジェクト用カスタムエージェント<repo>/.claude/agents/<name>.md

YAML frontmatter に name と description、本文に役割の指示を書きます。

04

コンテキストが長くなったら

Codex

CLI
/compact

会話を要約して継続。文脈を節約したいとき。

/clear

表示と会話をリセットして、新しいチャットを始める。

/new

画面表示を残したまま、新しいチャットを始める。

/status

コンテキスト使用量・チャット情報を確認する。

Claude Code

CLI
/compact

会話を要約して継続。必要なら要約の焦点も渡せる。

/clear

空の文脈で新しい会話を始める。/reset、/new も同義。

/context

現在のコンテキスト使用量と重い要素を可視化する。

/memory

読み込まれた CLAUDE.md・ルール・自動メモリを確認する。

05

「効いている？」の確認

Codex: 指示

codex --ask-for-approval never "Summarize the current instructions." で読み込まれた指示を確かめます。

Codex: スキルと子エージェント

/skills でスキルを探し、/agent または /subagents で子スレッドを確認します。

Claude Code: 設定全般

/memory、/skills、/agents、/doctor を使い分けます。

06

このリポジトリでの個人運用

端末を変えたときの最小セット

  • AGENTS.md と CLAUDE.md を ~/.codex/ と ~/.claude/ の両方へ配置する。
  • CLAUDE.md は @AGENTS.md で、同じディレクトリの共通指示を読む。
  • プロジェクト固有の規約は、グローバルファイルを膨らませず、そのリポジトリ内の指示ファイルへ置く。
